Como o arquivo .env deve estar para que o programa funcione corretamente?

1 - O env deve estar dentro da pasta "data" juntamente com o "conexoes.json"
2 - O env deve seguir o seguinte modelo para que o config.py consiga ler seus dados:

USUARIOWEBCAM=""
SENHAWEBCAM=""
IP=""
DB=""
DBF=""
PORTA=""
MINHAPASTA=""
PASTA_X=""
NOME_X=""

(Ao preencher todos os dados corretamente, o programa estara pronto para uso)
